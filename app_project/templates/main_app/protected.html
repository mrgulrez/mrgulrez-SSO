How Authentication Works

This application is protected by a centralized authentication system. Here's how it works:

  1. When you try to access a protected page, the system checks if you're authenticated.
  2. If not authenticated, you're redirected to the authentication service.
  3. After successful login, the auth service redirects you back with a secure token.
  4. This token is validated and stored in your session.
  5. Now you can access all protected resources until your session expires.
